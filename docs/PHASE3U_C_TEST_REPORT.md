## ข้อจำกัดที่รู้แล้ว (ผ่านบางส่วน)
1. **ไม่มีภาพตัวอย่างหน้า PDF** (เซิร์ฟเวอร์ไม่มีตัววาดหน้า) — จัดหน้าด้วยเลขหน้า/ขนาดกระดาษ
2. **รวม/แยก/ดึง/จัดหน้า ไม่คงบุ๊กมาร์ก ฟอร์ม และไฟล์แนบ** (ระบบเตือนก่อน) · หมุน/ลายน้ำ/ใส่-ปลดรหัส/ล้างข้อมูลแฝงคงไว้
3. **บีบอัดไม่ลดความละเอียดรูป** — ไฟล์ที่ส่วนใหญ่เป็นรูปจะเล็กลงน้อย
4. **ภาษาไทยในลายน้ำ/เลขหน้าใช้กฎแทนการจัดตัวอักษร OpenType เต็มรูป** — กรณีส่วนใหญ่ถูกต้อง แต่โปรแกรมดึงข้อความบางตัวอาจแทรกช่องว่างหลังวรรณยุกต์บน ป ฝ ฟ
5. **ไม่มี** Office→PDF, PDF→รูป, OCR, Redact, เปรียบเทียบ, PDF/A, ทำเป็นชุดเบื้องหลัง (แสดงเหตุผลในทะเบียนความสามารถ)
6. **ประมวลผลทันทีในคำขอเดียว** จำกัดโดยเวลา/หน่วยความจำของ PHP — บนโฮสต์ฟรีควรตั้งขีดจำกัดต่ำ
7. **ไฟล์ที่เข้ารหัสมา จะได้ผลลัพธ์ที่ไม่มีรหัส** (ระบบเตือน) — ใช้ "ใส่รหัสผ่าน" ต่อถ้าต้องการ
8. **สุ่มรางวัลแบบโอกาสเท่ากันเท่านั้น** (ไม่มีน้ำหนัก/สิทธิ์หลายครั้ง) · พยานเป็นชื่อที่พิมพ์ ไม่ใช่การอนุมัติด้วยบัญชีที่สอง · ผู้จัดสุ่มใหม่ได้ (ทุกครั้งบันทึกและแสดงในผล)
9. M29 ใช้รายชื่อจริงได้เมื่อย้ายขึ้นเซิร์ฟเวอร์จริงเท่านั้น (DEC-46) — หน้าแรกแสดงคำเตือน
