## ข้อควรรู้
- **ข้อความที่ AI ร่างยังใช้จริงไม่ได้** จนผู้มีความรู้ด้านกฎหมายตรวจ — ระบบบังคับให้เติมช่อง [[…]] และให้เจ้าหน้าที่อีกคนยืนยันการตรวจก่อนเผยแพร่
- ต้องมีผู้ถือบทบาท PRV อย่างน้อย 2 คน (คนร่างกับคนอนุมัติต้องต่างกัน)
- ประกาศเดิมที่อยู่ในแต่ละโมดูล (ผู้สมัคร GPS วันเกิด) ยังใช้ของโมดูลนั้น ยังไม่ได้เปลี่ยนให้ชี้มาที่ประกาศหลัก — M43/M16 (R6-2, R6-3) จะใช้ประกาศหลักโดยตรง
- ยังไม่มี: ส่งออกทะเบียนกิจกรรม/เหตุละเมิดเป็น Excel, การเตือนพนักงานที่ยังไม่รับทราบซ้ำ, แบบประเมินผลกระทบ (DPIA), ทะเบียนผู้ประมวลผลภายนอก (ใช้ทะเบียนการเชื่อมต่อเดิม)
