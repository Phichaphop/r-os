## ข้อจำกัดที่รู้แล้ว (ผ่านบางส่วน)
1. **เครื่องคำนวณตามกฎหมายใช้ไม่ได้จนกว่าจะกรอกตารางอัตราและมีคนที่สองอนุมัติ** — ระบบไม่มีค่าเริ่มต้น (ตั้งใจ) · ผลเป็นประมาณการเสมอ
2. **ภาษีเงินได้เป็นแบบง่าย**: เงินเดือน/ค่าจ้างเท่านั้น หักค่าใช้จ่าย + ลดหย่อนส่วนตัว + ค่าลดหย่อนตามรายการที่ตารางกำหนด ไม่รองรับเงินได้ประเภทอื่น เงื่อนไขซับซ้อนของค่าลดหย่อนแต่ละประเภท หรือการคำนวณหัก ณ ที่จ่ายรายเดือน (เป็นงานของ M36/M58)
3. **เงินเกษียณใช้ตารางขั้นเดียวกับค่าชดเชย** (DEC-60 ข้อ 1) — ถ้าบริษัทมีนโยบายเกษียณที่ต่างจากกฎหมาย ต้องรอโมดูล HR
4. ตารางอัตรากำหนดได้ระดับ **ทั้งกลุ่ม/รายบริษัท** ยังไม่ถึงระดับไซต์
5. **WOFF2 อ่านชื่อ/น้ำหนัก/เวอร์ชันจากไฟล์ไม่ได้** (ต้องใช้ Brotli ซึ่งไม่มีใน PHP ทั่วไป) — ตรวจโครงสร้างส่วนหัวและเก็บ/ดูตัวอย่าง/ดาวน์โหลดได้ปกติ
6. **การเผยแพร่ฟอนต์ต้องมีผู้ดูแลคลังฟอนต์อย่างน้อย 2 คน** (maker ≠ checker) — ระบบที่มีผู้ดูแลคนเดียวเผยแพร่ไม่ได้ (DEC-60 ข้อ 3)
7. หลักฐานลิขสิทธิ์แสดงเฉพาะฉบับล่าสุด (ฉบับเก่าอยู่ในที่เก็บเอกสาร ไม่แสดงในหน้าฟอนต์)
8. คลังฟอนต์ใช้ร่วมทั้งกลุ่มบริษัท ไม่แยกรายบริษัท (DEC-60 ข้อ 4)
