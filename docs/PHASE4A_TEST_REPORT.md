## ข้อจำกัดที่รู้แล้ว
- ลาเป็นวันและครึ่งวันเท่านั้น (ยังไม่มีลาเป็นชั่วโมง) · ครึ่งวันเฉพาะคำขอวันเดียว
- ปีลา = ปีปฏิทินเท่านั้น · วันที่ยกมาจากปีก่อนไม่มีวันหมดอายุภายในปี
- เปลี่ยนนโยบายกลางปีไม่คำนวณสิทธิ์ปีนี้ใหม่ — ใช้การปรับยอดแทน
- HR ยังยื่นลาแทนพนักงานไม่ได้ (พนักงานต้องมีบัญชี) · ยังไม่มีการอนุมัติทางอีเมล
- ยังไม่นับตามตารางกะ (M35 อยู่เฟส 5) — ใช้ปฏิทินวันทำงานของสาขา/บริษัท
- ยังไม่ส่งข้อมูลการลาไปเวลาทำงาน/เงินเดือน (event ถูกบันทึกไว้แล้ว ผู้รับมาใน 4B/4C)
- บัญชีวันลากันการแก้ที่ระดับโค้ด (ไม่มี trigger ในฐานข้อมูล)
