## ข้อจำกัด / ก่อนใช้จริง
- **ห้ามใส่ข้อมูลพนักงาน ใบเสร็จ หรือข้อมูลสุขภาพจริงบน InfinityFree**
- ประเภท วงเงิน และเงื่อนไขต้องมาจากระเบียบสวัสดิการของบริษัท — **ฝ่ายภาษีต้องกำหนดการเสียภาษีของรายการเงินได้ที่ใช้จ่าย** ระบบไม่ตัดสินแทน
- ใบเสร็จค่ารักษาพยาบาลเป็นข้อมูลสุขภาพ (PDPA) — DPO ควรยืนยันผู้เห็นและระยะเก็บ (`medical_claims` ยังเป็นร่างของ AI)
- วงเงินนับตามปีปฏิทินของวันที่เกิดค่าใช้จ่าย · ยอดรออนุมัติจองวงเงินตามลำดับที่ส่ง
- สถานะ "จ่ายแล้ว" อัปเดตทุกชั่วโมงและเมื่อเปิดหน้าจ่ายเงิน (อ่านจากรอบเงินเดือน/ชุดจ่ายเงิน)
