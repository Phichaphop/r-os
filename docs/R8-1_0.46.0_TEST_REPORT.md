## ข้อควรรู้
- **ไฟล์มีเลขประจำตัวเต็ม** เก็บไฟล์ในเครื่องที่ปลอดภัย และลบเมื่อยื่นเสร็จ ระบบไม่เก็บไฟล์นี้ (เก็บเฉพาะค่า SHA-256 ในประวัติของฉบับ)
- **ช่อง `0000` สองช่องในบรรทัด H:** ผู้ใช้ไม่แน่ใจว่าช่องไหนคือรหัสสาขา ระบบจึงให้กรอกแยกทั้งสองช่อง (ช่องที่ 1 และช่องที่ 6) พร้อมช่องที่ 3 (`000000`)
- **เลขประเภทการยื่น:** ไฟล์ตัวอย่างใช้ `2` แต่ไม่ได้บอกว่าเป็นการยื่นแบบใด จึงต้องกรอกทั้งเลขยื่นปกติและเลขยื่นเพิ่มเติมเอง
- **บรรทัดชื่อคอลัมน์:** ไฟล์ตัวอย่างมีบรรทัดแรกเป็นชื่อคอลัมน์ ถ้าระบบของหน่วยงานไม่รับ ให้เอาเครื่องหมาย "ใส่บรรทัดชื่อคอลัมน์" ออก
- **ลำดับที่สาขาประกันสังคม** ใช้ค่า "ลำดับที่สาขา" ในบัญชีนายจ้างประกันสังคม (สำนักงานใหญ่ใส่ 0 → ชีต `000000`)
- **คำนำหน้าชื่อ** ต้องมีในข้อมูลพนักงานทุกคนที่อยู่ในไฟล์
- ข้อมูลใน e2e เตรียมด้วยสคริปต์ (กติกาทดสอบ รอบเงินเดือน ต.ค. ฉบับที่อนุมัติ และเลขประจำตัวสมมุติ 19999…) ส่วนการเสนอค่าของไฟล์ หน้าจอ การยืนยันรหัสผ่าน และการดาวน์โหลดทำผ่านเบราว์เซอร์
