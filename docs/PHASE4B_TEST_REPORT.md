## ข้อจำกัดที่รู้แล้ว
- ยังไม่มีการอ่านเครื่อง HIP จริง — ตัวรับเวลาตอนนี้รับข้อมูลจากคำสั่ง `simulate`/`punch` เท่านั้น
- ยังไม่รองรับกะ งานข้ามคืน หรือตารางรายบุคคล — ใช้เวลาเดียวต่อกลุ่มพนักงาน (M35 อยู่เฟส 5)
- ยังไม่คำนวณ OT (M33 อยู่เฟส 5) และยังไม่ปิดงวด/ล็อกเวลา — คำขอแก้เวลาย้อนหลังจำกัดได้ด้วยจำนวนวันในเวลามาตรฐานเท่านั้น (4C)
- เปลี่ยนเวลามาตรฐานแล้วระบบไม่คำนวณย้อนหลังเอง ต้องกด "คำนวณเดือนนี้ใหม่" — งานตามรอบคำนวณเฉพาะเมื่อวานและวันนี้
- HR ยังยื่นขอแก้เวลาแทนพนักงานไม่ได้ · ยังไม่มีแจ้งเตือนลืมสแกน
- รายการรหัสที่ไม่มีเจ้าของตรวจช่วงวันที่แบบยืดหยุ่น ±1 วัน (เพื่อเลี่ยงการแปลงเขตเวลาในฐานข้อมูล)
- ข้อมูลสแกนดิบกันการแก้ไขที่ระดับโค้ด (ไม่มี trigger ในฐานข้อมูล) — เหมือนบัญชีวันลา
- ตัวรับเวลาเก็บรหัสลับของกุญแจในไฟล์ SQLite บนเครื่องสำนักงาน (สิทธิ์ไฟล์ 0600) — เครื่องนั้นต้องปลอดภัย
