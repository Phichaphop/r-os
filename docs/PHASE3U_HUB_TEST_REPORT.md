## ข้อจำกัด
- ยังเลือกขอ "ทั้งโมดูล" ไม่ได้โดยตรง เพราะบทบาทเป็นของทั้งระบบ — การขอใช้แอปจึงเป็นการขอบทบาทที่เปิดแอปนั้นได้ และบทบาทนั้นอาจเปิดแอปอื่นด้วย (ระบบแสดงให้เห็นว่าแอปไหนจะเปิดตาม)
- แอปบางตัวมีบทบาทเดียวที่เปิดได้และเป็นบทบาทใหญ่ (เช่น เอกสาร → HRA) — เป็นไปตามโครงบทบาทปัจจุบัน ถ้าต้องการบทบาทเล็กกว่า ต้องเพิ่มบทบาทใหม่ (เรื่องของเฟส HR)
- หน้าผู้ดูแลไม่แสดงเป็นช่องสีเทา — ผู้ที่ต้องการยังขอผ่านฟอร์มทั่วไป "ขอสิทธิ์ใช้งาน" ได้
- ปุ่มลัดหน้าหลักแบบมือถือของพนักงาน (P0-05 §2.3) รอโมดูลลงเวลา/ลา/สลิป/บัตร (เฟส 4–5)
