## ข้อควรรู้
- **ใบติดตามคือหลักฐานว่ามีการร้องเรียน** ระบบลดความเสี่ยงไว้แล้ว:
  - หัวใบเป็นกลาง และไม่มีเนื้อหาเรื่อง
  - มีคำเตือนให้เก็บในอุปกรณ์ส่วนตัว
  - ใครมีรหัสก็เปิดเรื่องได้
- **QR ใช้ส่วน `#`** ซึ่งไม่ถึงเซิร์ฟเวอร์ แต่แอปกล้องหรือเบราว์เซอร์ของมือถืออาจจำลิงก์ไว้ในประวัติของเครื่อง หน้าติดตามลบ `#` ออกจากแถบที่อยู่ทันทีที่เปิด
- **ที่อยู่ใน QR มาจาก `APP_URL`** ถ้าไม่ได้ตั้ง จะใช้ที่อยู่ที่เปิดอยู่ ควรตั้ง `APP_URL` เป็นที่อยู่ถาวร (https) ก่อนใช้จริง
- **ยังกู้รหัสผ่านระบบไม่ได้** ใบติดตามและ "เรื่องของฉัน" เป็นทางที่ผู้ร้องเก็บรหัสเอง ถ้าทั้งสองหาย ให้ส่งเรื่องใหม่และอ้างเลขที่เดิม (DEC-113)
