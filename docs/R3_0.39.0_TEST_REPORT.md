## ข้อควรรู้
- ภาพลายเซ็นบน PDF ไม่ได้พิสูจน์ตัวผู้เซ็นและไม่ป้องกันการแก้ไขภายหลัง (มีคำเตือนบนหน้า) — เอกสารที่ต้องตรวจสอบได้ใช้ M20 เซ็นเอกสารออนไลน์
- PDF ที่มีรหัสผ่านต้องปลดรหัสก่อนเซ็น (เครื่องมือ "ปลดรหัสผ่าน")
- บนโทรศัพท์ ลากด้วยนิ้วอาจไม่ทำงานในบางเบราว์เซอร์ ให้ใช้ปุ่ม ‹ › แทน
- ผลลัพธ์ที่ไม่ได้บันทึกหายไปจากรายการทันทีที่ออกจากหน้า — ต้องดาวน์โหลดหรือบันทึกก่อน (มีคำเตือนบนหน้าผล)
- ใน e2e พบว่า `page.waitForFunction` ของ Playwright ใช้ eval ซึ่ง CSP ของระบบปฏิเสธ (เป็นของเครื่องมือทดสอบ ไม่ใช่ของหน้า) → เปลี่ยนเป็นวนตรวจด้วย locator
