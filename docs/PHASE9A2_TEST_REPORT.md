## ข้อจำกัด / ก่อนใช้จริง
- **ห้ามใส่ข้อมูลพนักงานจริงบน InfinityFree** (เส้นทาง ผู้โดยสาร คนขับเป็นข้อมูลส่วนบุคคล)
- ภาพแผนที่ OpenStreetMap ใช้ฟรีสำหรับการใช้งานเบา ต้องแสดงเครดิต และอาจถูกจำกัดถ้าใช้หนัก · ถ้าใช้มากหรือขึ้น VPS แล้ว ควรตั้งผู้ให้บริการภาพแผนที่ของตัวเอง (เปลี่ยนที่อยู่ภาพได้ในหน้าตั้งค่า)
- ระยะเส้นตรงสั้นกว่าระยะขับจริงเสมอ — ใช้ดูคร่าว ๆ · ระยะจริงคิดจากเลขไมล์ · ถ้าต้องการตามถนน ใส่คีย์ OpenRouteService (แผนฟรีจำกัดจำนวนครั้งต่อวัน) — **ระบบจะส่งพิกัดต้นทาง–ปลายทางไปยังผู้ให้บริการ** (ผู้ใช้ยอมรับแล้ว 2026-11-01)
- InfinityFree: เบราว์เซอร์โหลดภาพแผนที่เอง จึงใช้ได้ · การเรียก OpenRouteService จากเซิร์ฟเวอร์อาจถูกโฮสต์บล็อก (ระบบกลับไปใช้เส้นตรง)
- กติกาที่ระบบกำหนดเอง (DEC-90): คำขอผ่านหัวหน้าสายงานเสมอ · คนเดียวมีคำขอซ้อนเวลาไม่ได้ · รายชื่อผู้เดินทาง ≤ 60 · ลิงก์รับจาก Google Maps / OpenStreetMap / Apple Maps เท่านั้น
