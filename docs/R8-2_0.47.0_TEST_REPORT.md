## ข้อควรรู้
- **ต้องกรอกที่อยู่แบบแยกช่องให้ครบทุกคน** ที่อยู่ในฉบับรายปีก่อนดาวน์โหลดไฟล์ทางการ ที่อยู่แบบข้อความเดิมยังอยู่ ระบบไม่แยกให้อัตโนมัติ
- **ยอดยกมา** ต้องอนุมัติก่อนสร้างฉบับรายปี ถ้าอนุมัติเพิ่มภายหลัง ฉบับจะขึ้นว่าล้าสมัยและต้องสร้างใหม่
- **ปีที่ยังไม่สิ้นปี** สร้างฉบับได้เพื่อตรวจยอด แต่มีคำเตือน ควรยื่นหลังสิ้นปีและรอบเงินเดือนธันวาคมอนุมัติแล้ว
- ข้อมูลใน e2e:
  - เตรียมด้วยสคริปต์: ยอดยกมาทดสอบของ D1-0001 และที่อยู่ทดสอบของ 34 คน
  - ทำผ่านเบราว์เซอร์: ที่อยู่ของ D1-0001 (กรอกผิดก่อน แล้วแก้), การสร้างฉบับ, การส่งอนุมัติ และการดาวน์โหลด
  - ผู้อนุมัติกดอนุมัติผ่านสคริปต์
