## ข้อควรรู้
- **รูปแบบผูกกับบริษัท** แต่ละบริษัทกำหนดของตัวเอง เพราะเลขที่บัญชีหรือรหัสลูกค้าที่ธนาคารให้ต่างกัน ใส่ค่าเหล่านี้ใน "ค่าคงที่ของบริษัท"
- **ค่าคงที่ของบริษัทไม่ใช่ที่เก็บความลับ** เพราะแสดงบนหน้าจอให้ผู้มีสิทธิ์ดูการจ่ายเงิน อย่าใส่รหัสผ่านหรือกุญแจ
- **ตรวจไฟล์แรกกับธนาคาร** ก่อนจ่ายจริง เช่น ทดลองอัปโหลดแบบไม่ยืนยันรายการ ถ้าระบบของธนาคารมีโหมดนี้
- ชุดจ่ายเงินที่สร้างไฟล์แล้ว ถ้าจะเปลี่ยนรูปแบบ ต้องยกเลิกไฟล์เดิม (มีเหตุผล) ก่อน ทำได้เฉพาะก่อนส่งธนาคาร
- ข้อมูลใน e2e:
  - เตรียมด้วยสคริปต์: ชุดจ่ายเงินทดสอบที่อนุมัติแล้ว (ผู้รับเงิน 3 คน เลขบัญชีสมมุติ) ชุดแรกสร้างผิด (ยอด 0) จึงยกเลิกไว้
  - ทำผ่านเบราว์เซอร์: การสร้างรูปแบบ การแก้ การเปิดใช้ การเลือกรูปแบบ และการดาวน์โหลด
