## ความปลอดภัยของผู้เยี่ยมชม (ตรวจโดยการอ่านโค้ด — REVIEWED ONLY)
- ผู้เยี่ยมชมได้ Authorizer userId 0 ที่มีเฉพาะสิทธิ์ของเครื่องมือที่ตรงกับ path · scope = บริษัท id 0 (ไม่มีอยู่จริง) → คิวรีตาม scope/เจ้าของคืนค่าว่าง
- path ที่อนุญาตเป็นรายการปิดใน manifest ของโมดูล (regex เต็มบรรทัด "METHOD /path") — path อื่นของโมดูลเดียวกันยังต้องเข้าสู่ระบบ
- CSRF ยังบังคับกับ POST ของผู้เยี่ยมชม (session เดียวกับหน้าเข้าสู่ระบบ)
- audit ของผู้เยี่ยมชมเป็น `anonymous` · สุ่มเร็วไม่บันทึกอะไรเลย · crypto ไม่บันทึกค่าที่กรอก (เหมือนเดิม)

## ข้อจำกัดที่ยังอยู่
- scope ระดับหน่วยงานยังไม่ไหลลงหน่วยลูก (ให้สิทธิ์ที่ Division ไม่ได้ครอบคลุม Section ใต้ Division อัตโนมัติ)
