## ขอบเขต (DEC-74) — คำสั่งผู้ใช้
> "แก้ไขให้ สุ่มรางวัล เหมือน สุ่มเร็วเลยได้ไหม ง่ายๆ ต่างกันแค่มีการบันทึกผล"

| สิ่งที่ทำ | ผล |
|---|---|
| หน้า **สุ่มรางวัล** (`/draw`) = หน้าจอเดียวกับสุ่มเร็ว: วงล้อ/วิ่งแข่ง + รายชื่อด้านขวา → คลิกวงล้อ → "ผู้โชคดีคือ" → นำชื่อออก/หมุนอีกครั้ง | PASS |
| ต่างจากสุ่มเร็วเฉพาะ: **สุ่มที่เซิร์ฟเวอร์และบันทึกทุกครั้งที่หมุน** · ช่องเพิ่ม 2 ช่องที่ไม่บังคับ (ชื่อการสุ่ม, รางวัลของการหมุนนี้) · รายการ "ผลที่บันทึกแล้ว" · ปุ่ม "จบการสุ่มและดูผล" | PASS |
| ไม่มีขั้นตอนสร้างกิจกรรม / นำเข้า / ตั้งรางวัล / ล็อก / เปิดหน้าจอสุ่มแยกอีกต่อไป — การหมุนครั้งแรกสร้างการสุ่มให้เอง | PASS |
| เปิดการสุ่มเดิมจาก "การสุ่มของฉัน" = ทำต่อได้ (รายชื่อล่าสุดกลับมา, ผลที่บันทึกแล้วแสดง) · จบแล้ว = เปิดหน้าผล (ดาวน์โหลด Excel/CSV, ตรวจสอบได้) | PASS |
| การสุ่มแบบเดิม (สร้างก่อน 0.11.2) ยังเปิด/สุ่มต่อ/ดูผลได้ตามเดิม แต่สร้างใหม่แบบเดิมไม่ได้แล้ว | PASS |

### ขั้นตอนตอนนี้
1. เปิด **สุ่มรางวัล** → วางรายชื่อ (ตั้งชื่อการสุ่ม/ชื่อรางวัลได้ถ้าต้องการ)
2. คลิกวงล้อ (หรือปุ่มหมุน / Space) — หมุนกี่ครั้งก็ได้ เปลี่ยนรางวัลก่อนแต่ละครั้งได้
3. กด **จบการสุ่มและดูผล** → หน้าผล

ความน่าเชื่อถือ: ค่าสุ่มลับ (seed) สร้างและบันทึกค่าผูกมัดตั้งแต่ก่อนหมุนครั้งแรก · ทุกครั้งที่หมุนเก็บรายชื่อที่ใช้ในครั้งนั้น · กดซ้ำ/เน็ตหลุดแล้วส่งใหม่ไม่สุ่มซ้ำ · ลบหรือแก้ผลไม่ได้ · จบแล้วเปิดเผย seed ให้คำนวณซ้ำได้ (ทดสอบว่าแก้ข้อมูลในฐานข้อมูลแล้วการตรวจจับได้)

## สิ่งที่เปลี่ยน/หายไป (แจ้งให้ทราบ)
- **ไม่มีการล็อกรายชื่อก่อนสุ่มแล้ว** — รายชื่อเปลี่ยนได้ระหว่างหมุน (เหมือนสุ่มเร็ว) แต่ทุกครั้งบันทึกรายชื่อที่ใช้จริงไว้ จึงตรวจย้อนหลังได้ว่าแต่ละครั้งสุ่มจากใคร
- **ไม่มีจำนวนรางวัลตั้งล่วงหน้า และไม่มี "สุ่มใหม่แทนคนสละสิทธิ์" แบบมีเหตุผล** — ให้หมุนอีกครั้งแทน (ทุกครั้งถูกบันทึก ลบไม่ได้)
- **ไม่มีช่องติ๊กยืนยันเรื่องกฎหมายแล้ว** เหลือเป็นข้อความเตือนในหน้า (กิจกรรมที่เรียกเก็บเงินหรือบังคับซื้อต้องตรวจกฎหมายก่อน)
- **ไม่มีนำเข้าไฟล์ Excel** — คัดลอกคอลัมน์ชื่อจาก Excel มาวางได้เลย (บรรทัดละ 1 ชื่อ)
- **ห้ามใส่รายชื่อพนักงานจริงบน InfinityFree**
