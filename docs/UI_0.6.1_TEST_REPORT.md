## การตัดสินใจออกแบบที่ควรรู้ (ขอ Sponsor ยืนยัน — บันทึกเป็น DEC-65)
1. **ฟอนต์จากลิงก์ = เซิร์ฟเวอร์ดาวน์โหลดเก็บเอง** ไม่ให้เบราว์เซอร์โหลดจาก Google โดยตรง เพราะ P0-02 §11 ห้าม CDN และ CSP เป็น `font-src 'self'` — ผลคือหน้าเว็บไม่ส่งข้อมูลผู้ใช้ไปที่ Google และ CSP ไม่ต้องผ่อน
   - ความปลอดภัย: https เท่านั้น · ไม่มี user/password หรือพอร์ตพิเศษในลิงก์ · ชื่อโฮสต์ต้องชี้ที่อยู่สาธารณะเท่านั้น (กัน SSRF ไปเครือข่ายภายใน/metadata) · ไฟล์ละ ≤ 5 MB รวม ≤ 25 MB ≤ 40 ไฟล์ · ต้องเป็นฟอนต์จริง (ตรวจ magic bytes) · CSS ที่ให้บริการ **สร้างใหม่** จากค่าที่แยกได้ ไม่ส่งต่อ CSS ที่ดาวน์โหลดมา
   - ช่องลิงก์ให้เฉพาะผู้ดูแล (สิทธิ์อนุมัติค่ากำหนดทั้งองค์กร) — ผู้ใช้ทั่วไปเลือกจาก dropdown (ไม่ให้ทุกคนสั่งเซิร์ฟเวอร์ไปดาวน์โหลดลิงก์ใดก็ได้)
   - ข้อจำกัดที่เหลือ: ตรวจที่อยู่ IP ก่อนดาวน์โหลด แต่ cURL resolve ชื่อซ้ำเอง (DNS rebinding ยังเป็นไปได้ทางทฤษฎี) — ยอมรับได้เพราะเฉพาะผู้ดูแลระดับสูงใช้ และ redirect ถูกปิด
2. **สุ่มรางวัลเป็นของผู้จัดเท่านั้น** — ผู้ดูแลระบบ (draw.manage) ก็ไม่เห็นการสุ่มของคนอื่นอีกต่อไป และยกเลิกการ "ประกาศผลให้ทุกคน" · ให้ทุกบทบาทสร้างการสุ่มของตัวเองได้ (`draw.use` ให้ทุกคน) — ก่อนหน้านี้เฉพาะ HR
3. **รีเซ็ตการสุ่ม** ไม่ลบอะไร: เริ่ม "ชุด" (generation) ใหม่ · ผลชุดเก่าคงอยู่ในฐานข้อมูลแต่ไม่แสดง · บันทึกค่าผูกมัดและ **เปิดเผย seed เดิม** ไว้ในประวัติ เพื่อให้ตรวจย้อนหลังได้ว่าผลเดิมไม่ได้ถูกแก้ · ต้องระบุเหตุผล
4. **โหมดจับฉลากเรียงลำดับ**: ตอนล็อกรายชื่อ ระบบสร้าง "รางวัล" แฝง 1 รายการ จำนวน = ทั้งรายชื่อ หรือจำนวนที่ระบุ · ไม่มีใครได้ซ้ำ · ผลแสดง "ผู้โชคดีลำดับที่ N" · สุ่มใหม่แทนคนที่สละสิทธิ์ได้โดยคงลำดับเดิม · การตรวจสอบย้อนหลัง (commitment/seed) ใช้กลไกเดิมทั้งหมด
5. แม่แบบ Excel มีเฉพาะหัวตาราง (ตัวอย่างอยู่อีกชีต) เพื่อไม่ให้ชื่อตัวอย่างหลุดเข้าการสุ่มจริง
6. ปฏิทินของพนักงานหาจากข้อมูลการจ้างงาน (สาขา → บริษัท → องค์กร) ถ้าไม่มีโมดูลพนักงานใช้บริษัทที่เลือกด้านบน · ทุกคนที่เข้าระบบเห็นปฏิทินของตัวเองได้ (ไม่ต้องมีสิทธิ์ `core.calendar.view` — ข้อมูลวันหยุดไม่ใช่ข้อมูลลับ) · ดูปฏิทินอื่นยังต้องมีสิทธิ์เดิม

## ข้อจำกัดที่รู้
- ขนาดแพ็กเกจเพิ่มประมาณ 0.9 MB (ฟอนต์ไทย 7 ตระกูล × 4 น้ำหนัก) — เบราว์เซอร์โหลดเฉพาะฟอนต์ที่หน้าใช้จริง ผู้ใช้ไม่ได้โหลดเพิ่ม
- ฟอนต์ที่นำเข้าเก็บใน `storage/fonts/` และ **ไม่อยู่ในไฟล์สำรองข้อมูล** (สำรองเฉพาะฐานข้อมูลและเอกสาร) — หลังกู้คืนบนเครื่องใหม่ ระบบกลับไปใช้ฟอนต์เริ่มต้นเองโดยไม่ error และลิงก์ต้นทางยังบันทึกไว้ (`theme.font_url`) ให้กดนำเข้าซ้ำได้
- ประวัติเครื่องคิดเลขอยู่ในหน้านั้นเท่านั้น (ไม่บันทึก ไม่ส่งออก) ตามหลักไม่เก็บข้อมูลเกินจำเป็น
