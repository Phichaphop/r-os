## ที่มา
ผู้ใช้แจ้ง (2026-11-02): "เมนูด้านข้างเยอะเกินไปมากสำหรับผู้ดูแล ช่วยเพิ่ม/ลด หรือกลุ่มรวม ย่อ/ขยายให้หน่อย"
ก่อนแก้: ผู้ดูแล HR เห็นเมนูหลัก **59 รายการ** ต่อกันยาว (เมนูโมดูลทุกตัวรวมใน "งานของฉัน" กลุ่มเดียว · ตั้งค่าโมดูลปนกับตั้งค่าระบบ)
หลังแก้: หน้าแรกของผู้ดูแล HR / ผู้ดูแลระบบเห็น **9 ลิงก์** (งานของฉัน) + หัวกลุ่มที่พับไว้ 9–10 กลุ่ม

## สิ่งที่เปลี่ยน
| ส่วน | เนื้อหา |
|---|---|
| หมวดเมนูโมดูล | สื่อสารและเอกสาร · บุคลากร · เวลาและการลา · เงินเดือนและสวัสดิการ · งานสำนักงาน · เครื่องมือ · การเงิน — คีย์ `nav_section` ใน module.json (ไม่ใส่ = ใช้ pack, ค่าที่ไม่รู้จัก = ตรวจไม่ผ่าน) · HR 18 โมดูลแบ่ง 3 หมวด |
| เมนูย่อยต่อโมดูล | รายการที่ 2+ ของโมดูลเดียวกันในกลุ่มเดียวกัน = เมนูย่อยพับไว้ (เช่น ข้อมูลพนักงาน › รายงาน) |
| หน้าของฉัน | ลิงก์ `/me/...` (ข้อมูลของฉัน สลิปเงินเดือนของฉัน) อยู่ใน "งานของฉัน" |
| ตั้งค่าโมดูล | กลุ่มแยก "ตั้งค่าโมดูล" — "ตั้งค่า" เหลือเฉพาะของระบบ |
| พับ/ขยายกลุ่ม | หัวกลุ่มเป็นปุ่ม `aria-expanded` + `aria-controls` · จำสถานะต่อเครื่อง (localStorage) · กลุ่มที่มีหน้าปัจจุบันเปิดเสมอ · กลุ่มที่พับแสดงจำนวนงานรอรวม |
| ค่าเริ่มต้น | เมนูหลัก ≤ 14 รายการ = เปิดทุกกลุ่ม · มากกว่า = เปิดเฉพาะ "งานของฉัน" + กลุ่มของหน้าปัจจุบัน |
| ค้นหาเมนู | ช่องค้นหา (เมนูยาว) กรองตามชื่อเมนู เปิดกลุ่ม/เมนูย่อยที่ตรง · ไม่พบ = ข้อความแจ้ง · Esc ล้างและคืนสถานะเดิม |
| โหมดย่อแถบ (rail) | แสดงไอคอนทุกตัว + เส้นคั่นกลุ่ม · **แก้บั๊กเดิม:** เมนูย่อยที่พับไว้ไม่แสดงในโหมดย่อ (reset.css ซ่อน `[hidden]` แบบ !important) |
| การเข้าถึง | ลิงก์โลโก้และปุ่มย่อเมนูมีชื่อ (เดิม axe แจ้ง button-name / link-name ในโหมดย่อ) |
