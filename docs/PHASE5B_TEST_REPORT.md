## ข้อจำกัดที่ยังอยู่
- แก้ OT หลังส่ง Payroll แล้วยังไม่มี workflow — ต้องทำใน Payroll (เฟส 6)
- เปลี่ยนเวลาของรูปแบบกะ มีผลกับวันที่ยังไม่ได้ล็อกที่ใช้กะนั้นอยู่ (ต้องใส่เหตุผล + บันทึก audit) — ถ้าต้องการเวลาใหม่เฉพาะช่วงต่อไป ให้สร้างรูปแบบกะใหม่
- ยังไม่มีการตรวจ "ทักษะ/จำนวนคนขั้นต่ำต่อกะ" (สเปกระบุว่า "ตามกฎที่ยืนยัน" — ยังไม่มีกฎ)
- หัวหน้า (MGR) ตัวอย่างได้ scope ทั้งบริษัท จึงจัดกะได้ทั้งบริษัท — ใช้จริงควรกำหนด scope เป็นหน่วยงาน
- **ห้ามใส่ข้อมูลบุคคลจริงบน InfinityFree**
