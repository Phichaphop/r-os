## ข้อจำกัดที่รู้แล้ว
- ยังไม่มีเงินเดือน/บัญชีธนาคารในประวัติ (เฟส 6) — หมวด E มีแค่ช่องเก็บเอกสาร
- ผู้ตรวจภายใน (AUD) เห็นแค่รายงานความครบ ยังไม่มีสิทธิ์อ่านแฟ้มแบบจำกัดเวลา (6.19.4)
- เลขประจำตัวที่ใกล้หมดอายุ (เช่น ใบอนุญาตทำงาน) ยังไม่แจ้งเตือน — แจ้งเฉพาะเอกสารในแฟ้ม
- เช็กลิสต์พ้นสภาพ HR เป็นคนติ๊ก — ยังไม่ส่งงานไปหาผู้รับผิดชอบแต่ละฝ่าย
- การพ้นสภาพทำให้บัญชีเป็น "offboarding" — ผู้ดูแลระบบยังต้องปิดบัญชีถาวรเอง
- ยังไม่มีการนำเข้าประวัติพนักงานจากไฟล์
- การเปลี่ยนสังกัดยังไม่คำนวณเวลาทำงาน/สิทธิ์ลาที่ได้รับผลกระทบย้อนหลังให้อัตโนมัติ — มี event ให้โมดูลอื่นรับ แต่ยังไม่มีผู้รับ
