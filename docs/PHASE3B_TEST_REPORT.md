## ข้อจำกัดที่รู้แล้ว (ผ่านบางส่วน)
1. **PDF:** ระบบ "อ่าน" PDF ได้ระดับตรวจความปลอดภัย (สคริปต์, รหัสผ่าน, จำนวนหน้า) แต่ยังสร้าง/รวม/แยก PDF เองไม่ได้ — เอกสารจากแม่แบบใช้ "พิมพ์ → Save as PDF" ของเบราว์เซอร์ (6.10 ข้อ 4 อนุญาต) · เครื่องมือ PDF เต็ม (S01) อยู่ใน 3U
2. **ฟอนต์เอกสาร:** ใช้ชื่อฟอนต์ TH Sarabun New ถ้าเครื่องผู้ใช้มีฟอนต์นี้ (Windows/Office ส่วนใหญ่มี) ถ้าไม่มีจะใช้ฟอนต์สำรอง — ยังไม่มีการอัปโหลดไฟล์ฟอนต์พร้อมหลักฐานสิทธิ์ (DEC-28)
3. **ตัวแก้ไขแม่แบบ** เป็นช่อง HTML อย่างง่าย + ดูตัวอย่าง ยังไม่มีตัวแก้ไขแบบเห็นผลทันที (WYSIWYG)
4. **ไม่มีสแกนไวรัส** บนโฮสต์ปัจจุบัน — ลดความเสี่ยงด้วยการรับเฉพาะชนิดที่กำหนด, ปฏิเสธมาโคร/สคริปต์, เก็บนอกเว็บ, ไม่เปิดไฟล์บนเซิร์ฟเวอร์, ส่งไฟล์พร้อม CSP sandbox
5. **ค้นหา** จากชื่อ รหัส เลขที่ เท่านั้น ไม่ค้นเนื้อหาในไฟล์ (ไม่มี OCR)
6. **นำเข้า Excel** ตอนนี้มีชุดเดียว (วันหยุด) — โครงกลางพร้อมให้โมดูลถัดไปเพิ่ม (พนักงาน, ยอดยกมา ฯลฯ) · การส่งออกจำนวนมากยังทำทันที (จำกัดแถวด้วย `export.max_rows`) ยังไม่เป็นงานเบื้องหลัง
7. **ระยะเวลาเก็บรักษาทุกค่าเป็นร่างของ AI** ไม่มีผลจนกว่า Legal/ผู้ทำบัญชียืนยันและอีกคนอนุมัติ (DEC-48) — ยังไม่มีการเก็บไฟล์ใดถูกกำหนดวันทำลาย
8. **วันหยุดราชการ** ไม่ได้ใส่ให้ (ไม่เดาข้อมูลทางการ) — ผู้รับผิดชอบเพิ่มหรือนำเข้าจากประกาศจริง
9. **MFA ยังปิดเป็นค่าเริ่มต้น** (DEC-52) — ข้อเสนอให้เป็นเงื่อนไขของ Activation Gate ยังรอยืนยัน
