## ข้อควรรู้
- **ต้องติดตั้งใหม่ทั้งหมด** (ชื่อภายในเปลี่ยน) — ไฟล์สำรองจาก R-OS เดิมกู้คืนไม่ได้ · Collector ต้องใช้ชุดใหม่
- หลังติดตั้ง **ต้องมอบบทบาท "เจ้าหน้าที่ความปลอดภัย (จป.)"** ให้ผู้ดูแลงานความปลอดภัย มิฉะนั้นไม่มีใครจัดการเหตุ
- โลโก้ของระบบเป็นสีขาว ใช้บนพื้นสีเข้มเท่านั้น (แถบเมนู หน้าเข้าสู่ระบบ บัตรพนักงาน) · การระบายสีโลโก้ต้องใช้ไฟล์พื้นโปร่งใส (PNG/WebP) — ไฟล์ JPG จะกลายเป็นสี่เหลี่ยมทึบ
- คลังฟอนต์: สิทธิ์ fonts.manage ยังอยู่ที่ SYS — ถ้าต้องการให้ "ใครก็ได้" อัปโหลด/เผยแพร่ ให้มอบสิทธิ์เพิ่มในหน้าบทบาท (ระวังลิขสิทธิ์ฟอนต์)
- ไฟล์ สปส.1-10.xlsx ที่ได้รับมีเลขประจำตัวประชาชน — ไม่ได้เก็บลงโค้ด (R8 ใช้ข้อมูลสมมุติ)
- ผู้ดูแลระบบเห็นโครงการได้แล้ว (เปลี่ยนจาก DEC-101) — แจ้งพนักงานว่าการเปิดดูของผู้ตรวจสอบ/ผู้ดูแลระบบถูกบันทึก audit
- เครื่อง e2e: dev server หยุดเมื่อครบเวลาที่กำหนด (ปกติ)
