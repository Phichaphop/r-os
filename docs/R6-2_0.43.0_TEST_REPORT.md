## ข้อควรรู้
- ต้องเผยแพร่ **ประกาศความเป็นส่วนตัวกลุ่มผู้มาติดต่อ** ในศูนย์ความเป็นส่วนตัวก่อนใช้จริง — หน้าของผู้มาติดต่อจะลิงก์ไปเอง
- สิทธิ์จุดรับ: บทบาท WPA (และ SFO) · ถ้า รปภ. ใช้ระบบ ให้สร้างบทบาท/มอบสิทธิ์ `visitors.gate` เฉพาะจุดรับ
- ระบบไม่ส่งอีเมล/SMS ให้ผู้มาติดต่อ — ผู้ลงทะเบียนคัดลอกลิงก์ส่งเอง
- ระยะเก็บและการแจ้งอยู่เกินเวลาไม่มีค่าเริ่มต้น — บริษัท/เจ้าหน้าที่ความเป็นส่วนตัวกำหนดเอง
- ยังไม่มี: พิมพ์บัตร/สติกเกอร์, แบบรับทราบกฎความปลอดภัย, เชื่อมเหตุความปลอดภัย, CCTV, ส่งออก Excel, ข้อมูลส่วนบุคคลของผู้มาติดต่อในคำขอเจ้าของข้อมูล (DSR)
