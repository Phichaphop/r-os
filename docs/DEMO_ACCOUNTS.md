# บัญชีทดสอบของบริษัทตัวอย่าง (รุ่น 0.40.0)

> ข้อมูลจำลองทั้งหมด (ชื่อ ตำแหน่ง เงินเดือน ทะเบียนรถ) — **ห้ามใช้ข้อมูลจริงบน InfinityFree**
> ติดตั้งใหม่แบบ "มีข้อมูลตัวอย่าง" แล้วจะได้บริษัทตัวอย่าง 1 แห่ง (DEMO1 "บริษัทตัวอย่าง จำกัด") ครบทุกฝ่าย พนักงาน 35 คน และบัญชีด้านล่าง
> ทุกบัญชีใช้รหัสผ่านเดียวกัน ซึ่งแสดง **ครั้งเดียว** ที่หน้าติดตั้งเสร็จ (Q-20, DEC-106)

## โครงสร้างองค์กร
```
บริษัทตัวอย่าง จำกัด (DEMO1) — สาขา: สำนักงานใหญ่ (HQ) · สาขาตัวอย่าง 1 (BR1) · โรงงานตัวอย่าง (FAC1)
└─ คณะผู้บริหาร (EXEC)
   ├─ ฝ่ายตรวจสอบภายใน (IA)
   ├─ สายงานบริหารและสนับสนุน (DIV-ADM)
   │  ├─ ฝ่ายบุคคล (HR) ── แผนกสรรหาและพัฒนาบุคลากร (HR-REC) · แผนกค่าตอบแทนและเงินเดือน (HR-PAY)
   │  ├─ ฝ่ายบัญชี (ACC) · ฝ่ายการเงิน (FIN) · ฝ่ายเทคโนโลยีสารสนเทศ (IT)
   │  ├─ ฝ่ายธุรการและอาคารสถานที่ (GA) ── แผนกยานพาหนะ (GA-VEH)
   │  └─ ฝ่ายกฎหมายและคุ้มครองข้อมูล (LEGAL)
   ├─ สายงานปฏิบัติการ (DIV-OPS) — โรงงาน FAC1
   │  ├─ ฝ่ายผลิต (PROD) ── แผนกผลิต A (PROD-A) ── หน่วยผลิต A กะเช้า (PROD-A1)
   │  └─ ฝ่ายประกันคุณภาพ (QA) · ฝ่ายซ่อมบำรุง (MAINT) · ฝ่ายคลังสินค้า (WH) · ฝ่ายความปลอดภัยฯ (SHE)
   └─ สายงานพาณิชย์ (DIV-COM)
      └─ ฝ่ายขาย (SALES, สาขา BR1) · ฝ่ายการตลาด (MKT) · ฝ่ายจัดซื้อ (PUR)
```

## บัญชีและสิ่งที่ใช้ทดสอบ
| บัญชี | คนในบริษัท (ฝ่าย) | บทบาท | ใช้ทดสอบ |
|---|---|---|---|
| `exec.demo1` | กรรมการผู้จัดการ (EXEC) | EXE ผู้บริหาร | แดชบอร์ดผู้บริหาร · อนุมัติโครงการ |
| `exec.br1` | ผู้จัดการสาขา 1 (SALES) | EXE (สาขา) | แดชบอร์ดระดับสาขา |
| `hr.head1` | ผู้จัดการฝ่ายบุคคล (HR) | HRA | ตั้งค่า HR · อนุมัติข้อมูลพนักงาน (คนละคนกับผู้แก้) |
| `hr.demo1` | เจ้าหน้าที่บุคคล (HR) | HRA | ทะเบียนพนักงาน · ประกาศ · เอกสาร · e-ID |
| `hr.officer1` | เจ้าหน้าที่สรรหาและฝึกอบรม (HR-REC) | HRT | สรรหา · อบรม · ลา/OT/กะ ในฐานะ HR · คลังความรู้ |
| `payroll.maker` | เจ้าหน้าที่เงินเดือน (HR-PAY) | PYO ผู้ทำ | เตรียมงวดเงินเดือน · ภ.ง.ด./สปส. (ฝั่งผู้ทำ) |
| `payroll.checker` | หัวหน้าแผนกค่าตอบแทน (HR-PAY) | PYA ผู้อนุมัติ | อนุมัติงวดเงินเดือน (maker ≠ checker) |
| `finance.maker` | เจ้าหน้าที่การเงิน (FIN) | FNM | บัญชี/การเงิน ฝั่งผู้ทำ · อัตรากำลัง |
| `finance.checker` | ผู้จัดการฝ่ายบัญชี (ACC) | FNC | อนุมัติ/ปิดงวดบัญชี · ตัดจำหน่ายทรัพย์สิน |
| `wallet.officer1` | เจ้าหน้าที่กระเป๋าเงินพนักงาน (FIN) | WAL | เติมเงิน/นโยบายกระเป๋าเงิน e-ID (ข้อกฎหมาย ธปท. ต้องตรวจก่อนใช้จริง) |
| `cashier.br1` | แคชเชียร์สาขา 1 (SALES) | CSH (สาขา) | งานแคชเชียร์ระดับสาขา |
| `manager.demo1` | หัวหน้าฝ่ายขาย (SALES) | MGR | อนุมัติลา/OT/กะ ของทีมขาย · ขอคน · อนุมัติอบรม |
| `manager.prod1` | ผู้จัดการฝ่ายผลิต (PROD) | MGR | อนุมัติของทีมผลิต (`/leave/team`, `/attendance/team`) |
| `employee.demo1` | พนักงานขาย (SALES) | EMP | สิทธิ์พนักงานทั่วไป: ลา · OT · เบิกของ · จองห้อง · แจ้งซ่อม |
| `worker.prod1` | พนักงานฝ่ายผลิต รายวัน (PROD-A1) | EMP | พนักงานรายวันในโรงงาน: กะ · ลงเวลา · ลา · แจ้งเหตุความปลอดภัย |
| `ga.demo1` | เจ้าหน้าที่ธุรการและอาคาร (GA) | WPA + SFO | ห้องประชุม · ล็อกเกอร์ · ยานพาหนะ · เบิกอุปกรณ์ · แจ้งซ่อม · ตรวจเช็ค · ทรัพย์สิน · ความปลอดภัย |
| `safety.demo1` | เจ้าหน้าที่ความปลอดภัย (SHE) | WPA | อนุมัติใบอนุญาตผู้รับเหมา · ประตูผู้รับเหมา (ผู้อนุมัติคนที่สอง) |
| `driver.demo1` | พนักงานขับรถ (GA-VEH) | EMP + คนขับ | บันทึกเที่ยววิ่ง/เลขไมล์ |
| `tech.demo1` | ช่างซ่อมบำรุง (MAINT) | EMP + ช่าง | รับงานซ่อม · บันทึกผลตรวจเช็ค |
| `dpo.demo1` | เจ้าหน้าที่คุ้มครองข้อมูลส่วนบุคคล (LEGAL) | PRV | คำขอเจ้าของข้อมูล · บันทึกกิจกรรมการประมวลผล |
| `dpo.demo2` | (ไม่ผูกพนักงาน) | PRV | ผู้ตรวจคนที่สองของงานความเป็นส่วนตัว |
| `auditor.demo` | ผู้ตรวจสอบภายใน (IA) | AUD (อ่านอย่างเดียว) | ประวัติการใช้งาน (audit) · ดูโครงการ/ทรัพย์สิน |
| `sysadmin2.demo` | ผู้ดูแลระบบไอที (IT) | SYS | ผู้ดูแลระบบคนที่สอง (อนุมัติการตั้งค่าที่ต้องสองคน) |

## เส้นทางทดสอบตัวอย่าง (ข้อ 11)
| เรื่อง | ผู้ขอ | ผู้อนุมัติ/ผู้ปฏิบัติ | หน้า |
|---|---|---|---|
| เบิกอุปกรณ์สำนักงาน | `employee.demo1` หรือ `worker.prod1` ส่งคำขอ | `ga.demo1` อนุมัติและจ่ายที่จุดจ่าย (สแกน QR/บาร์โค้ด) | `/requisition` · `/requisition/issue` |
| จองห้องประชุม | `employee.demo1` | `ga.demo1` จัดการห้อง | `/rooms` |
| ล็อกเกอร์ | — | `ga.demo1` จัดสรรล็อกเกอร์ให้พนักงาน | `/lockers` · `/lockers/admin` |
| จองรถ | `employee.demo1` | `ga.demo1` อนุมัติ · `driver.demo1` วิ่งและบันทึกเลขไมล์ | `/vehicles` |
| แจ้งซ่อม | `worker.prod1` | `ga.demo1` มอบงาน · `tech.demo1` ซ่อมและปิดงาน | `/helpdesk` |
| ตรวจเช็ค (checklist) | — | `ga.demo1` สร้างรอบ · `tech.demo1` ตรวจ | `/inspection` |
| ลา / OT | `worker.prod1` | `manager.prod1` อนุมัติ (ใน `/approvals`) | `/leave` · `/overtime` |
| เงินเดือน | `payroll.maker` เตรียม | `payroll.checker` อนุมัติ | `/payroll` |

> **ก่อนทดสอบการลา:** ระบบไม่ใส่จำนวนวันลาให้ (เป็นข้อกำหนดตามกฎหมายและนโยบายบริษัท) — `hr.demo1` ตั้งนโยบายการลาที่ `/leave/admin` แล้ว `hr.head1` อนุมัติ ก่อนหน้านั้นการยื่นลาจะขึ้นว่า "HR ยังไม่ได้ตั้งนโยบายของประเภทนี้"
>
> การจับเวลาจากเครื่องสแกนนิ้ว (รหัสผู้ใช้เครื่อง) มีให้เฉพาะพนักงาน 7 คนแรก (D1-0001…0007) — คนอื่นเพิ่มได้ที่หน้าตั้งค่าเครื่องลงเวลา
