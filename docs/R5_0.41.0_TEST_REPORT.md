## ข้อควรรู้
- แชทไม่ใช่เรียลไทม์แท้ — ข้อความของอีกฝ่ายมาถึงภายใน 5–10 วินาที (ตามที่เลือก Q-01) ไม่ใช้ WebSocket เพราะโฮสต์ไม่รองรับ
- แต่ละคนที่เปิดห้องค้างไว้ = 6–12 คำขอต่อนาที ควรสังเกตภาระบน InfinityFree ตอน UAT
- ผู้ดูแลไม่มีทางอ่านแชทอื่นในระบบ (ไม่มีหน้า "ดูทุกห้อง") — ตามที่เลือก Q-05
- ติดตั้งใหม่ไม่มีข้อมูลแชทตัวอย่าง
