# Blue OS Time Collector (จำลอง) — เฟส 4B

โปรแกรมเล็กที่ติดตั้ง **ในสำนักงาน** ข้างเครื่องสแกน (DEC-30, DEC-33, ADR-007)
- รับเวลาสแกนจากเครื่อง แล้วเก็บไว้ในไฟล์ SQLite
- เปิด **Punch API แบบอ่านอย่างเดียว** ให้ Blue OS มาดึงข้อมูลทุก 4 ชั่วโมง (ปรับได้)

> **สถานะ:** ส่วนอ่านข้อมูลจากเครื่อง HIP ของจริง **ยังไม่มี**
> - ต้องรู้ชื่อโปรแกรม HIP และรูปแบบข้อมูลก่อน (DEC-43, BT-02)
> - ระหว่างนี้ใช้ `simulate` (ข้อมูลจำลอง) หรือคำสั่ง `punch` แทน
> - ส่วนที่ต้องเขียนเพิ่มคือ `src/Reader/ReaderAdapter.php`

## สิ่งที่ห้ามมีในระบบนี้ (DEC-25)
- ไม่มีช่องเก็บลายนิ้วมือ ภาพใบหน้า แม่แบบชีวมิติ หรือเลขบัตรประชาชน
- API ส่งเฉพาะข้อมูลต่อไปนี้:
  - รหัสผู้ใช้ในเครื่อง
  - เวลา
  - วิธียืนยันตัว (finger / face / card / password)
  - เลขเครื่อง
- Blue OS จะปฏิเสธรายการที่มีช่องข้อมูลลักษณะชีวมิติ

## ติดตั้ง (PHP 8.1+ พร้อม pdo_sqlite)
```bash
# 1) เครื่องสแกน
php collector/bin/collector device:add SIM-BR1-01 --serial=SIMBR101 --model=CiF510-FP --tz=Asia/Bangkok

# 2) เปิด Punch API (ให้บริการเฉพาะโฟลเดอร์ public — ไฟล์ข้อมูลอยู่นอกโฟลเดอร์นี้)
COLLECTOR_DB=/path/นอกเว็บ/collector.sqlite php -S 0.0.0.0:8787 -t collector/public
#    ใช้งานจริงต้องมี HTTPS ด้านหน้า (tunnel หรือ reverse proxy — ADR-008)
```

3) ตั้งค่าใน Blue OS ที่หน้า **การเชื่อมต่อ → hip.time_collector**
   - ใส่ที่อยู่ปลายทาง (endpoint)
   - บันทึกผลประเมินความเป็นส่วนตัว
   - ตั้งสถานะเป็น "ใช้งาน"
   - กด "ออกกุญแจ" (รหัสลับแสดงครั้งเดียว)

4) เพิ่มกุญแจที่ Collector:
```bash
php collector/bin/collector key:add rk_xxxxxxxxxxxxxxxx      # ระบบจะถามรหัสลับ (ไม่แสดงบนจอ)
```

5) ใน Blue OS ไปที่ **ตัวรับเวลา → ดึงข้อมูลตอนนี้**
   - ตั้งชื่อเครื่องและเลือกสาขา
   - ผูกรหัสผู้ใช้กับพนักงานที่หน้า **ตั้งค่าเวลาทำงาน**

## ข้อมูลจำลอง
```bash
php collector/bin/collector simulate SIM-BR1-01 --from=2026-11-02 --to=2026-11-06 \
    --users=000103,000104,000105,000106,000107 --late=000104:25 --miss=000105:out --absent=000106@2026-11-04 --double=000103
php collector/bin/collector punch SIM-BR1-01 000104 "2026-11-09 08:03:00" card
php collector/bin/collector status
```

## Punch API v1 (สรุป — รายละเอียดใน P0-03 §12)
- `GET /v1/punches?after={cursor}&limit={1..1000}`
- `GET /v1/health`
- ทุกคำขอต้องลงลายเซ็น HMAC-SHA256 โดยใช้ส่วนหัว:
  - `X-Blue-Key-Id`
  - `X-Blue-Timestamp` (คลาดได้ไม่เกิน 300 วินาที)
  - `X-Blue-Nonce` (ใช้ได้ครั้งเดียว)
  - `X-Blue-Signature`
- รหัสตอบกลับเมื่อผิดพลาด:

| รหัส | ความหมาย |
|---|---|
| 400 | cursor หรือ limit ผิด |
| 401 | ลายเซ็นไม่ผ่าน |
| 404 | ไม่มีเส้นทางนี้ |
| 405 | ไม่ใช่ GET |
| 429 | เรียกเกิน 120 ครั้ง/นาที |

- ไม่มี endpoint สำหรับเขียนหรือลบข้อมูล
